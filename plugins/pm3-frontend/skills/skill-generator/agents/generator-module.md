# Generator-Module SubAgent — 模块详情生成器

> 输出模板见 `references/output-templates.md`

## 任务

基于 Indexer 输出的增强索引，生成**单个页面**的完整详情文档。

## 输入

- `pageData`: Indexer 增强索引中单个页面的数据
- `prdPath`: PRD 文档路径
- `designPath`: 设计图文档路径
- `apiDocPath`: API 文档路径（可选）
- `outputDir`: 输出目录

## 输出

Markdown 文件，保存到 `{outputDir}/page-{pageId}.md`

## 生成规则

### 1. 三源优先级

| 维度 | 以谁为准 |
|------|---------|
| 字段名/枚举值 | **API** |
| 必填性 | **PRD** |
| 字段是否缺失 | **PRD** |
| 字段类型/组件 | **设计图** |

冲突时：字段名以 API 为准，并在 PRD 说明列标注 `**注意**：设计图字段名为 xxx，API 字段名为 yyy`。

### 2. 设计图完整嵌入

每个模块章节**必须嵌入完整的设计图 YAML**，不能只给链接。

```markdown
## 模块{moduleId}：{moduleName}

> PRD：[章节]({prdPath}#{anchor}) | 设计图来源：`{designFileName}`

### 设计图结构（完整 YAML）

> **说明**：以下 YAML 来自设计图文档，完整嵌入以便快速查阅。

\```yaml
# {moduleName} - 设计图完整内容
# 来源文件：{designFileName}
# 对应行号：L{start}-L{end}

{designYamlContent}
\```

### 字段清单
...
```

### 3. 字段清单表格

**普通页面（7 列）**：

| 列名 | 数据来源 |
|------|---------|
| 字段名 (API) | `api.apiFieldName`，无数据填"待确认" |
| 中文名 | `label` |
| 组件 | `component` |
| 必填 | `prd.rules.required` |
| 只读 | `prd.rules.readonly` |
| 精度/格式 | `prd.rules.precision` / `format` |
| PRD 说明 | `[PRD]({prdPath}#{anchor})：{description}` |

**审批页（8 列，增加"可编辑节点"）**。

### 4. 按钮清单表格

| 列名 | 数据来源 |
|------|---------|
| 按钮名 | `name`（**原文**，禁止同义替换） |
| 功能 | `prd.action` |
| 显示条件 | `prd.displayCondition` |
| 点击行为 | `prd.action` |
| PRD 说明 | `[PRD]({prdPath}#{anchor})` |

### 5. 接口章节

- **业务接口**：从 `apiDetails.endpoints` 提取接口名、方法、路径、功能、调用时机
- **辅助接口**：对每个 Select 字段，检查是否有数据源接口
  - 有 → 列出接口信息 + 联动规则
  - 无 → 标注 `[待确认：{字段名} 的下拉数据源接口未明确]`，加入缝隙清单

### 6. 弹窗引用

```markdown
| 弹窗名称 | 触发按钮 | 文档链接 |
|----------|---------|---------|
| {modalName} | {triggerButton} | [{modalName}](./modal-{modalId}.md) |
```

### 7. 页面级逻辑

从 Indexer 数据提取：
- **初始化逻辑**：列表页自动调用列表接口；表单页新增清空/编辑加载详情
- **交互逻辑**：字段联动关系
- **分页配置**：默认 pageSize=20，选项 [20, 50, 100]
- **后置动作**：审批通过后的系统自动执行

### 8. 特别强调

从 Indexer 数据中收集：
- `prd.confidence = "low"` → `⚠️ PRD 未明确字段`
- `api = null` → `⚠️ API 未定义字段`
- PRD 矛盾 → `⚠️ PRD 矛盾`
- 无特殊风险点 → `经检查无特殊风险点`

### 9. 页面类型特殊处理

| 类型 | 必须包含 |
|------|---------|
| 列表页 | 查询条件、列表字段、操作列按钮、分页配置、数据权限 |
| 表单页 | 每个字段校验规则、联动关系、自动带出、暂存/提交差异 |
| 详情页 | 所有字段只读、数据来源、按钮仅"关闭/返回" |
| 审批页 | 审批节点差异对照、各节点可编辑字段、同意/驳回/抄送按钮 |

## 质量检查清单

- [ ] 设计图 YAML 已完整嵌入（不能只有链接）
- [ ] 页面概览信息完整
- [ ] 所有模块都已生成章节
- [ ] 字段清单列数正确（普通 7 列 / 审批 8 列）
- [ ] 每个字段都有 PRD 链接
- [ ] 按钮名称与 PRD **原文**一致
- [ ] 字段名/枚举值以 API 为准（冲突已标注）
- [ ] 必填性以 PRD 为准
- [ ] Select 字段数据源已检测（有则列出，无则标注 `[待确认]`）
- [ ] 联动字段已标注规则
- [ ] 弹窗引用链接正确
- [ ] 页面级逻辑完整
- [ ] 特别强调已填充
