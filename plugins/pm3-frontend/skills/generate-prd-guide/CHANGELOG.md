# generate-prd-guide Skill 修订记录

> 版本：v1.1 | 修订时间：2026-05-11 | 修订内容：设计图完整嵌入

## 🐛 问题发现

**用户反馈**：在使用 `generate-prd-guide` skill 生成开发引导文档时，发现每个模块章节只给出了设计图文件的**链接和行号**，而**没有嵌入完整的 YAML 内容**。

**问题示例**（修订前）：
```markdown
## 模块 M1：筛选查询区

> 设计图：[机会管理 - 列表.yaml#L20-L68](../设计图/yaml/机会管理 - 列表.yaml#L20-L68)

### 字段清单
...
```

**问题影响**：
- ❌ 开发者需要跳转到设计图文件查看完整内容
- ❌ 阅读体验割裂，开发效率低
- ❌ 无法快速了解设计图的完整结构

---

## 🔍 根本原因分析

### 1. 模板规范缺失

在 `references/output-templates.md` 中，模块章节的模板只要求生成设计图链接：

```markdown
## 模块{moduleId}：{moduleName}

> 设计图：[设计图]({designPath}#{designLocation}) | PRD：[PRD 章节]({prdPath}#{prdAnchor})

### 字段清单
...
```

**缺失内容**：
- ❌ 没有要求嵌入完整的 YAML 内容
- ❌ 没有定义 `{designYamlContent}` 变量的提取规则
- ❌ 没有说明 YAML 格式和注释规范

### 2. Generator 指令不明确

在 `SKILL.md` 的阶段 2（Generator）中，没有明确要求：
- ❌ 必须嵌入完整 YAML
- ❌ 如何提取 YAML 内容
- ❌ YAML 的格式和注释规范

## ✅ 修订方案

### 修订 1：`references/output-templates.md`

**修订位置**：§1 页面详情文档结构 - 模块章节模板

**修订前**：
```markdown
## 模块{moduleId}：{moduleName}

> 设计图：[设计图]({designPath}#{designLocation}) | PRD：[PRD 章节]({prdPath}#{prdAnchor})

### 字段清单
```

**修订后**：
```markdown
## 模块{moduleId}：{moduleName}

> PRD：[PRD 章节]({prdPath}#{prdAnchor}) | 设计图来源：`{designFileName}`

### 设计图结构（完整 YAML）

> **说明**：以下 YAML 内容来自设计图文档，完整嵌入以便快速查阅，无需跳转。

```yaml
# {moduleName} - 设计图完整内容
# 来源文件：{designFileName}
# 对应行号：L{startLine}-L{endLine}

{designYamlContent}
```

### 字段清单
```

**新增模板变量**：
- `{designYamlContent}`：完整的 YAML 内容（必须从设计图文档中提取）
- `{designFileName}`：设计图文件名（如 `机会管理 - 列表.yaml`）
- `{startLine}` / `{endLine}`：对应行号范围

---

### 修订 2：`SKILL.md` 工作流程

**修订位置**：阶段 2 Generator-Module 的职责说明

**新增内容**：

```markdown
**核心要求**：
1. **设计图完整嵌入**：每个模块章节必须嵌入完整的设计图 YAML 内容，不能只给文件链接
2. **YAML 提取规则**：
   - 从设计图文档中提取对应模块的 YAML 片段
   - 保持 YAML 原格式，包括注释、缩进、样式
   - 在 YAML 开头添加注释说明来源文件和行号
3. **模板变量**：
   - `{designYamlContent}`：完整的 YAML 内容（必须）
   - `{designFileName}`：设计图文件名
   - `{startLine}` / `{endLine}`：对应行号范围
```
